# 节奏能手 · 微信小游戏

一个面向休闲游戏爱好者的方向键节奏小游戏：图标从顶部掉落，进入底部横线触发区时按下对应方向的按键即命中，按错或漏接即结束。无需登录，界面简洁、图标统一风格（矢量箭头，无 Emoji）。

## 玩法
- 顶部统计总分，底部有 上 / 左 / 右 / 下 四个方向按键（对应四条轨道）。
- 图标落入横向触发区时，按下对应方向键 = 命中（+5 分，正中 +10 分）。
- 按错方向 或 图标掉落出触发区 = 游戏结束。
- 随时间推移：同时掉落的图标变多、下落速度加快（已限制在人类可反应范围内）。
- 结束后可分享成绩，不同分数段对应不同成就称号。

## 目录结构
```
music-master/
├─ index.html          # 浏览器预览（直接双击/用本地服务器打开即可玩）
├─ game.js             # 微信小游戏入口
├─ game.json           # 小游戏配置
├─ project.config.json # 开发者工具项目配置
└─ src/
   └─ core.js          # 与运行环境无关的游戏核心（浏览器/小游戏共用）
```

## 浏览器预览（无需微信）
直接用浏览器打开 `index.html` 即可：
- 鼠标点击底部四个方向区，或使用键盘方向键 ← ↑ ↓ →。
- 空格 / 回车 = 开始 / 再玩一次。
- 结束后点击「分享成绩」生成分享卡。

建议用本地服务器以避免个别浏览器对本地脚本的限制：
```bash
cd music-master
python3 -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080/index.html
```

## 导入微信开发者工具
1. 打开微信开发者工具 → 导入项目。
2. 目录选择 `music-master/`（含 `game.js` 的根目录）。
3. AppID 可选「测试号」(`touristappid`) 或填入自己的小游戏 AppID。
4. 编译即可在模拟器运行；真机预览可体验触摸与震动反馈。

## 自定义
- 难度曲线：`src/core.js` 中 `update()` 的 `dur`（下落时长）与 `interval`（生成间隔）上限/下限。
- 配色与方向：`src/core.js` 顶部 `DIRS`（四个方向、颜色、箭头角度）。
- 成就阈值：`src/core.js` 顶部 `ACHIEVEMENTS`。
