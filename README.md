# 节奏能手 · 微信小游戏

一个面向休闲游戏爱好者的方向键节奏小游戏：图标从顶部掉落，进入底部横线触发区时按下对应方向的按键即命中，按错或漏接即结束。无需登录，界面简洁、图标统一风格（矢量箭头，无 Emoji）。

## 玩法
- 顶部统计总分，底部有 左 / 上 / 下 / 右 四个方向按键（对应四条轨道）。
- 图标落入横向触发区时，按下对应方向键 = 命中（+5 分，正中 +10 分）。
- **生命值**：初始 3 点（顶部爱心展示）。按错方向 或 漏接掉落 只扣 1 点生命，**生命耗尽才游戏结束**（更友好、不易劝退）。
- **复活**：游戏结束后若本局还有复活次数（默认 1 次），可点击「复活继续」——清场并恢复满血、保留当前分数继续游玩。
- 随时间推移：同时掉落的图标变多、下落速度加快（已限制在人类可反应范围内）。
- 结束后可分享成绩，不同分数段对应不同成就称号。

## 目录结构
```
music-master/
├─ index.html          # 浏览器预览（直接双击/用本地服务器打开即可玩）
├─ game.js             # 微信小游戏入口
├─ game.json           # 小游戏配置
├─ project.config.json # 开发者工具项目配置
└─ src/
   ├─ core.js          # 与运行环境无关的游戏核心（浏览器/小游戏共用）
```

## 声音
全部由 Web Audio 实时合成，不含任何受版权保护的乐曲或采样，可安全发布：
- **整体风格**：空灵清脆的钟铃音（正弦基频 + 八度 + 钟铃非谐泛音，极快起音、闪烁长尾），无方波/锯齿的刺耳感。
- **开始**：上行钟铃琶音（C5→E5→G5→C6）明亮空灵开场。
- **倒计时**：3 / 2 / 1 每拍清亮「滴答」，结束后「GO」上扬双铃信号音。
- **命中 / 完美**：清脆通透的铃音（完美命中更高更亮、带闪烁泛音）。
- **失败 / 失误**：柔和下行的「叹息」音（正弦下滑 + 柔尾），不刺耳。
- **背景音乐**：游戏中循环播放的原创合成旋律（I–V–vi–IV 进行 + 轻底鼓/踩镲），进入游戏淡入、结束时淡出。

## 本地最高分 / 生命值 / 复活
- **本地最高分**：成绩自动保存在本地（浏览器 `localStorage` / 微信 `wx.getStorageSync`，key 为 `rmns_best`），主菜单与结算页展示「历史最高」；刷新纪录时结算页显示「★ 新纪录 ★」。
- **生命值**：顶部以矢量爱心（无 Emoji）展示剩余生命，初始 3 点，失误扣 1 点，归零才结束。
- **复活**：结算页在还有复活次数时显示金色「复活继续」按钮（默认每局 1 次），点击清空当前下落图标、恢复满血并继续本局（保留分数与已达成的最高分）。

## 浏览器预览（无需微信）
直接用浏览器打开 `index.html` 即可：
- 鼠标点击底部四个方向区，或使用键盘方向键 ← ↑ ↓ →。
- 空格 / 回车 = 开始 / 再玩一次。
- 结束后点击「分享成绩」生成分享卡。

建议用本地服务器以避免个别浏览器对本地脚本的限制：
```bash
cd music-master
python3 -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080/index.html
```

## 导入微信开发者工具
1. 打开微信开发者工具 → 导入项目。
2. 目录选择 `music-master/`（含 `game.js` 的根目录）。
3. AppID 可选「测试号」(`touristappid`) 或填入自己的小游戏 AppID。
4. 编译即可在模拟器运行；真机预览可体验触摸与震动反馈。

## 自定义
- 难度曲线：`src/core.js` 中 `update()` 的 `dur`（下落时长）与 `interval`（生成间隔）上限/下限。
- 配色与方向：`src/core.js` 顶部 `DIRS`（四个方向、颜色、箭头角度）。
- 成就阈值：`src/core.js` 顶部 `ACHIEVEMENTS`。
- 生命 / 复活：`src/core.js` 中 `maxLives`（生命点数）、`maxRevives`（每局复活次数）。

## 版本规划（Roadmap）
按发布节奏把功能拆到不同版本线，便于排期与回归：

### v1.0（当前版本 · 已发布）
- 核心玩法：4 方向节奏命中、渐进难度（限速在人类反应范围内）。
- 界面：大厂风格 UI（玻璃拟态、辉光、脉冲触发区、动画倒计时、命中爆点、失败震屏）。
- 音频：空灵清脆的钟铃音效 + 原创合成背景音乐（规避版权）。
- 社交/成就：分享卡 + 10 档成就称号。
- **留存增强**：本地最高分、3 点生命值、每局 1 次复活。

### v1.1（体验打磨）
- 暂停：切后台 `onHide` 自动暂停，回到前台恢复（微信端必做，避免切出丢分）。
- 静音 / 音量开关：分别控制 BGM 与音效，尊重系统静音。
- 命中音按方向变音高（左低右高），连起来像在「弹琴」，强化音乐感。
- 新手引导：首次进入用箭头指引「落入横线时按对应键」。

### v1.2（微信生态）
- 微信群排行榜：`openDataContext` 实现好友/群周榜（经典裂变）。
- 安全区适配：刘海屏、iPhone 底部 Home 指示条，避免按键被遮挡。

### v1.3（商业化）
- 激励视频 / 插屏广告：`wx.createRewardedVideoAd`，与复活 / 双倍得分联动。
- 复活与广告打通：看广告续命，提升留存与变现。

### v2.0（玩法扩展）
- 长按音符（Hold）：带尾迹的箭头需「按住」方向键到尾端，丰富操作维度。
- 连击里程碑特效：combo 10/25/50 触发全屏粒子 + 专属音效。
- 失败慢动作回放、BGM 随连击叠层升级紧张感。
